> **Day:** Day 20 · **Date:** 2026-08-06

## Overview

FarmBridge now sends professional, responsive HTML emails for all major business events. The system extends the existing layered architecture (Entity → Repository → Service → Controller → Exception → Security) **without breaking a single existing API or altering business logic**. All email HTML is generated by **one reusable template**; all sends are **fail-safe** (email failures never roll back business logic).

## 4. Backend Changes

- **Fail-safe design:** every send is wrapped — `sendHtml()` catches `Exception`, logs a `WARN`, and never rethrows; the announcement loop additionally guards each recipient so one failure never stops the remaining emails. Verified by test: SMTP failure → order/verification still committed.
- **HTML escaping:** all user-controlled values (names, reasons, messages, button URLs) are escaped before being placed in the template — no HTML/script injection.
- **Backward compatibility:** `OrderStatusRequest.reason` is optional; all existing order-status payloads work unchanged.
- **Transactions:** email sends happen inside the existing transactional service methods but can never roll them back.

## 5. Frontend Changes

- **Admin Announcement page:** audience dropdown, subject, message, optional button text/URL, **live HTML preview**, send with loading state, success/error toasts, and an announcement history table (audience, subject, recipients, date).

## 10. End-to-End Flow

```
Registration ──► Welcome email
Farmer verification ──► Admin approves ──► Approved email   │  Admin rejects ──► Rejected email (+reason, resubmit button)
Order placed ──► New Order email → farmer
Order accepted ──► Accepted email → buyer
Order rejected ──► Rejected email → buyer (+reason)
Order completed ──► Completed email → buyer (review CTA)
Forgot password ──► HTML reset email (15-min expiry)
Admin announcement ──► Audience filter (ALL/BUYERS/FARMERS) ──► one HTML email per matching user
```
